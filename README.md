# Student Management System

## Overview
Student Management System is a Python-based application that allows users to manage student records efficiently using MySQL as the backend database.

## Features
- Add Student
- Update Student
- Delete Student
- Search Student
- Display All Students
- MySQL Database Connectivity
- Input Validation
- Menu Driven Interface

## Technologies Used
- Python
- MySQL
- mysql-connector-python

## Installation

Install the required package:

```bash
pip install mysql-connector-python
```

## Run

```bash
python student_management_system.py
```
